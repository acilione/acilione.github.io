Microcontrollers

STM32 Microphone Recorder
Source code
Button-controlled audio capture on the B-L475E-IOT01A Discovery board. C firmware records its onboard MEMS microphone through DFSDM and DMA, then transfers audio over ST-LINK USB to a Python receiver that saves 16 kHz WAV files. Includes buffered capture, packet checksums, lost-data detection, and host tests.
C, Python STM32, DFSDM, DMA, CMake
